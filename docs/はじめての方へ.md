# はじめての方へ

パソコンに詳しくなくても大丈夫です。順番どおりにやれば15分ほどで終わります。

やることは大きく2つだけです。

1. Google で「アプリパスワード」を作る（10分くらい）
2. Fukidashi を落としてダブルクリックする（5分くらい）

---

## 1. アプリパスワードを作る

Fukidashi があなたのメールを読むための、**専用のパスワード**を作ります。
ふだん使っている Google のパスワードは使いません（教える必要もありません）。

### 1-1. 2段階認証をオンにする

<https://myaccount.google.com/signinoptions/two-step-verification> を開いてください。

すでにオンになっていれば、次へ進んでください。オフの場合は画面の案内に
従ってオンにします。携帯電話の番号が必要です。

> **なぜ必要か**：Google の決まりで、2段階認証をオンにしないと
> アプリパスワードを作れません。

### 1-2. アプリパスワードを作る

<https://myaccount.google.com/apppasswords> を開きます。

「アプリ名」を聞かれるので **Fukidashi** と入力して、「作成」を押してください。

すると `abcd efgh ijkl mnop` のような**16文字**が表示されます。
これがアプリパスワードです。

**この画面は一度閉じると二度と表示されません。** コピーしておくか、
このまま次の手順に進んでください。

> **これは何か**：メールボックスを読むための鍵です。大事に扱ってください。
> もし不安になったら、同じページからいつでも取り消せます。取り消すと
> Fukidashi が読めなくなるだけで、Google アカウント本体には影響しません。

## 2. Fukidashi を入れる

### Windows の方

1. [Releases](../../releases/latest) から **Fukidashi-Windows.zip** を落とす
2. 落とした zip を右クリック →「すべて展開」
3. 出てきた **Fukidashi.exe** をダブルクリック

#### 「Windows によって PC が保護されました」と出たら

出ます。びっくりしなくて大丈夫です。

青い画面の左下にある小さな **「詳細情報」** を押してください。
下に **「実行」** というボタンが出るので、それを押します。

> **なぜ出るか**：Microsoft に料金を払って登録した開発元でないソフトには、
> 一律でこの警告が出ます。中身が危ないという意味ではありません。
> 気になる方はソースコードを全部読めます（このページの上の方にあります）。

#### ウイルス対策ソフトに止められたら

まれに誤って検知されることがあります。その場合はお手数ですが、
このアプリを「除外」に追加するか、使用を見送ってください。

### Mac の方

1. [Releases](../../releases/latest) から **Fukidashi-macOS.zip** を落とす
2. 展開して出てきた **Fukidashi** を「アプリケーション」フォルダに入れる
3. ダブルクリックする

> **2番を飛ばさないでください。** ダウンロードした場所のまま開くと、macOS が
> アプリを一時領域に写して動かします（App Translocation）。その領域はあとで
> 消えるため、しばらく使っていると画面が出なくなります。必ず「アプリケーション」
> へ移してから開いてください。

#### 「"Fukidashi" は開いていません」と出たら

必ず出ます。びっくりしなくて大丈夫です。
**「ゴミ箱に入れる」は押さないでください。**

1. ダイアログの **「完了」** を押す
2. **システム設定** → **プライバシーとセキュリティ** を開く
3. 下のほうへスクロールすると「セキュリティ」の欄に
   **「"Fukidashi" は … ブロックされました」** という行と
   **「このまま開く」** ボタンがあるので、それを押す
4. Touch ID かパスワードで認証する
5. 最後にもう一度確認されるので **「開く」** を押す

次からはふつうにダブルクリックで開きます。

> **この表示は、開こうとした直後にしか出ません。** システム設定に
> 見当たらない場合は、もう一度アプリを開こうとしてから見てください。

> **なぜ出るか**：Apple に年額を払って登録した開発元のアプリでないと、
> macOS がこの警告を出します。中身が危ないという意味ではありません。
> ソースコードはすべて公開されています。

> **昔の「右クリック → 開く」は使えません。** macOS 15 (Sequoia) から
> Apple がその抜け道を廃止したため、上の手順が唯一の方法です。

#### ターミナルが使える方へ

次の1行でも解決します（ダウンロードに付く隔離の印を外します）。

```bash
xattr -dr com.apple.quarantine /Applications/Fukidashi.app
```

## 3. 最初の設定

アプリを開くと、順番に聞かれます。

1. **Gmail のアドレス** — 読みたいメールアドレスを入れます
2. **表示する名前** — 画面に出る短い名前です（「しごと」「プライベート」など）
3. **転送されたメールがあるか** — よく分からなければ「ない」で構いません
4. **アプリパスワード** — さきほどの16文字を貼り付けます

終わるとブラウザが開いて、メールの取り込みが始まります。
3か月分で数分かかります。コーヒーでも淹れて待ってください。

---

## 4. ふだんの使い方

- アプリを開くとブラウザで開きます
- 新しいメールは3分ごとに勝手に入ってきます（右上の「同期」でも取り込めます）
- **「人」タブ**にはやりとりのある相手が、**「お知らせ」タブ**には
  お店やサービスからの通知が入ります
- やめるときは画面右上の **「終了」** を押します

## よくある質問

**メールが勝手に既読になりませんか？**
なりません。Fukidashi は読むだけで、Gmail 側には一切手を加えません。
削除もラベルの変更もしません。

**返信はできますか？**
できません。読む専用です。返信は Gmail で行ってください。

**メールはどこかに送られますか？**
送られません。あなたのパソコンの中だけで処理されます。
Fukidashi にはサーバーがありません。作者もあなたのメールを見られません。

**パスワードはどこに保存されますか？**
Windows は「資格情報マネージャー」、Mac は「キーチェーン」という
OS の金庫に入ります。設定ファイルには書き込まれません。

**使うのをやめたいときは？**
アプリを削除して、<https://myaccount.google.com/apppasswords> から
アプリパスワードを取り消してください。それだけです。

**うまく動かないときは？**
[Issues](../../issues) に書いてください。Mac の場合は
`~/Library/Logs/Fukidashi.log` に手がかりが残っています。
